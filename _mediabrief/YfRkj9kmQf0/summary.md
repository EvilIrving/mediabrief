## 这是一场什么访谈

Silicon Valley Girl（主持人 Marina）采访 Ali Miller。Ali 为企业和高管做 AI 顾问，材料里提到客户包括 OpenAI、Google、Anthropic 相关的业务场景。访谈想讲得很落地：不是「AI 能聊天」，而是 **让系统在你睡觉时替你跑起来**。Ali 说真正想给观众的是心态转变，以及少一点对下一步的恐惧。

## 从问答助手到可委托的工作流

Ali 的对比：大约两年前，AI 能做研究、给综述，你还得自己拿去落地；大约一年到一年半前进入她说的 agentic 阶段，系统可以替你行动、接管数小时工作。

她自称的产能：只当问答助手大约 **20–30%**；能委托工作后，视任务大约 **2x 到 10x**。Marina 追问「一年后设了 Claude 和没设的人差在哪」——放到后面她的回答。

## Ali 自己的系统长什么样

她描述（不是观众配额）：**36 个主动工作流**、大约 **28 个 master agents**，平均再各拉约 2 个子代理；Marina 按「每个工作流」乘出来上千，Ali 当场改口：合计大约 **100 个 agents**。关键不是数量，而是 **不必每天亲手踢一脚**——每天早报、盯竞品这类「你反正会问」的动作应该排程。她点名可在 Claude Cowork、Claude X、Claude Code 里调度。

多数结果进邮箱、分文件夹。例子：周五把近 5 天 Gmail 里未回的紧急邮件按紧急度排序、起草回复、可委派同事、不回就提醒；每天 morning briefing：行业新闻、纽约/旧金山当日可社交的事、会前材料——日历上有 Fortune 500 CEO/CFO 见面时，回一个关键词就能让 agent 做会议资产。

她说接下来讲的 **不要求你会写代码**；背后抓 Gmail、Google Workspace、Fireflies、Granola 通常走 API，但你用自然语言即可。

## 「先抱怨」，再让它采访你

Ali：最好的起点是向 Claude 抱怨（伞、会议空隙、深度工作时间、安卓/iPhone 照片乱）。她要的不只是情绪认同，而是把问题解决掉。另一个做法：让它用内置 **ask user questions** 技能采访你，再进规划。

## Claude 的四种界面

Ali 分四层（她说别家也有多形态）：

- **网页 Claude Chat**：单线程问答、能上网、好接 Notion/Gmail 等预置连接器；**较难替你真正行动**。
- **Claude Cowork**：偏商务的 agentic 平台，能对桌面本地文件采取行动（例如做 Google Doc）。
- **Claude Code**：控制、定制、写软件都更强。
- **Chrome 扩展**：在具体网页上接管鼠标/窗口（她举 Walgreens 做拼贴海报）。

她说前面讲的 skills 可用于前三者。

Skill：她比作工具箱里的扳手——长提示加一点「额外花样」，可复用、可新建（品牌语气、去 AI 腔、通讯稿、问卷纪要等）。本质是一个文件夹：说明要做什么、可能连哪个工具、加示例/资源。Claude 有 skill creator。技能还可以迁到 Perplexity、ChatGPT 等；代理之间也会互相传递模块（例如共同的「反 AI 套话」技能）。她提醒：Claude 说「我不会做 skill」时你仍可能需要顶回去，**emotional fortitude 还重要**。

她还有一套口头框架：microtasker / company / delegate / teammate。现场搭的 morning brief 她觉得更像 **delegate**；若早报发给全队、去读 Jira 进度，则更像 **teammate**（抬的是系统而不只是个人）。她很反感「AI 是聪明实习生」这种说法。企业痛点：个人超级用户 3x、5x 却囤着不分享；中小企业可用共享 teammate 降低落后同事的摩擦。

## 现场演示：一份 morning brief（示例，不是唯一方案）

Marina 用语音演示，人设是「Apple TV 高管、还不信任所以暂不接日历/邮箱、旧金山」：行业新闻（按「进门能让老板刮目」或「必须知道的热议」取前三）、行业相关「最疯 AI 新闻」（还故意要求隔词用 game changer / wild）、天气穿衣、未来 4 天旧金山活动。

Ali：她已不太想「提示词工程」； ramble 一两分钟是为了把压力、怪癖等细微处说进去。Claude 追问送达时间与格式，她们选 **早上 6 点、Word Doc**，右上角进度条按步执行（含 skill creator）。演示稿出来后 Ali 建议：可改成直接发给老板的消息；嵌入 LinkedIn 语气 skill；活动要链接和价格。起步很容易做的两个 skill：语气、品牌规范。

## 先写哪三份文件

假设你在做自己的事（小生意、社媒；带两个孩子的家庭也被她算成一种事业）：

1. **Personal constitution**：核心是谁、价值观（她举 entrepreneurship / high agency）；硅谷有人入职就互发这种文档。
2. **2026 目标**：年/季/月/周，习惯加减，例如一周跑两次、每周家庭晚餐、差旅少 30%。
3. **核心业务策略**：服务谁/不服务谁、价值主张；网站上没有的颜色（播客试了三年为何失败、为什么住在某城）。

她建议把这段访谈丢给 Claude，让它问你一小时，你走路用嘴答，让它写这三份；之后 Chat / Cowork / Code 都能调用。她在 AWS 时执行可能年中大改，North Star 尽量不动。她团队做过全体静音开摄像头的一小时 **context hack**。Marina：这 20 分钟是投资，第一周可能省三小时。嫌建档烦，也可以向 Claude 抱怨，她预期它会用很少几个高信号问题，先做到「一半像你」。

## 为什么不是 ChatGPT

Ali：两年前约 99% 用 ChatGPT，现在约 99% 用 Claude Code——因为她要教很多人，必须跟各家。听众转 Claude 的常见理由是语气、共情、「一点描述就能铺开」，**较少**是「agent 工作流特别精密」。她仍建议先选定 **ChatGPT、Claude 或 Gemini 之一**，并去试各家的 agentic 形态（OpenAI 的 Codex 等、Claude 的 Code 与 Cowork）；几周后排名可能变。记忆导入、把 md 放进一个文件夹，迁移没有很多人想的那么难。桌面/Drive/SharePoint 稍微整齐一点，她觉得是接下来一年的 hack。

## 钱怎么收，她的业务变在哪

Ali 团队大约一周前改成 **按成片/产出、保底质量付费**，不再按小时；她觉得「一小时」这个概念被打乱了。她举例：给附近餐馆做网站，两天变成一小时，买方并不会自己解决问题，不必按 1/48 收费。

她自己最大变化：当更撑得住的顾问——把与各行业 AI/产品/创始人的见闻做成仅客户可见的 recap，按每个大客户的 context stock 规模化定制，并标明哪段是 AI 生成、哪段自己审过。她把通讯、步骤都当成 **赠送的 context**，鼓励读者丢进自己的系统。

## 看 Marina 团队的项目怎么摆

Marina 团队说俄语，按 clips、Telegram、PR、Spotify、两个 YouTube、Facebook、Instagram 分项目。Ali 喜欢按媒介/业务纵切，也喜欢横切（整体设计、整体 PR、如何用 Claude）；项目之间她猜未必能直接互连，或许可导出文件做成 skill——她自称 **不太用 Cowork**，让 Marina 去问 Claude，功能一直在变。

下一步她建议一个全公司级「新品开发」项目：脑暴、纪要、别人产品的链接，当参谋/类似首席参谋，能看见人力从 0 个工程师到 3 个 ML 工程师的变化。角色可以做成会互动的 skills。Cowork 左侧 customize → browse plugins：品牌语气、客服、数据/SQL、财务、工程、法务等，她说中小企业等于多了「大致免费」的编外成员。法务合同先过插件和自己的脑子，再给律师，她举过 2 小时变 15 分钟——仍是辅助，不是替代。

## 什么时候信它

Marina 提到一项研究：肯尼亚创业者里，新手把决策全交给 ChatGPT 把生意做垮，老手则 10x。Ali 的读法：差别不一定是专业本身，而是 **懒惰地外包一切 vs 用它来挑战、增强**；企业里超级用户和落后数年的人，差在把 AI 当工具还是当 teammate/操作系统。领域内你较能看出真假；量子物理她说自己没判断力，也有人被说得像发明了新科学。多模型交叉、给它上网和你接受/拒绝过的合同及原因，有助于接地。她去年年度词是 agency：既卸担子又留下自己的判断。她还强调 **知道什么叫好**（不一定会做平面也能判断广告好不好）；职场新人可与见过几十年行业的人组队；去开会、读本领域论文原文而不只让 AI 摘要；也要质疑自己过去对「好流程」的定义。

材料里还提到：有创始人按 ChatGPT 建议为了不付 200 美元解雇人，反被起诉、亏得更多——当作反例，不是建议。

## 她觉得 12 个月可能发生什么

她每年发 AI 预测（自称跟了 8 年、自己觉得算准、很多领域比预测更快），完整 25 条不在这场里展开。当场说的「不那么显而易见」的一点：**真自学习**——现在对话/记忆多半是塞进上下文或 RAG，不是权重在变；未来模型可能自己更新，触发来自环境（听了 Marina 五个月招聘讨论，发现录了纽约的 Jeff Smith，就更新她更偏向高风险高回报）。方向是每人一套 AI 操作系统、**market of one**（她点过 Flint 一类实时定制落地页）；代理给代理写信她已经在 Gmail/Instagram 上见到。她认为人际真实关系会更重要，否则只剩代理在网上碰面会很孤独；但代理先碰头也能加快事。

团队：小团队能干现在大团队的活。有的公司会砍 75% 编制（8 个社媒经理变 2 个）；有的把人挪去 YouTube、70 种语言音频、新渠道、专人维护 AI skills。Marina：近三四周尤其明显，社媒产出大约 **5x**，做客座 outreach 的人也兼 PR 和 GEO；她不打算裁员，想 10x 产出。

一年后设了系统的人：少反复重配、答案更贴自己；更大希望是新功能出来时没那么怕——她估恐惧降 **30–70%**，来自暴露和练习。收入 **不保证涨**：有人今年主动降收、全力转 AI；她更希望财务稳定、收入多元、聪明地省。她说自己做 AI 近 20 年、最近十年每天都在做，是因为对个人生意有用，也想帮到很多人。
