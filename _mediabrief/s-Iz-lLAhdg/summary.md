## 这是一场什么访谈

Silicon Valley Girl（Marina Mogilko）采访 Khan Academy 创始人兼 CEO Sal Khan。开场介绍：每年约 1 亿人在上面学习；Sal 做过早期 AI 辅导。上一本书是《Brave New Words》（写于 2023，关于 AI 与教育）；正在写的是《Job Shock》。Marina 问过去两年变了什么——Sal 的回答是：教育侧许多三年前还是想法的东西已在发生；同时他对就业冲击越来越担心。

中段有两处不是 Sal 的内容：HubSpot for Startups 赞助（Marina 自己的七个 Claude skill 与「自动化/初稿+人审/纯人工」框架），以及 Inner Circle newsletter 导流。

## 从乐观到 Job Shock

Sal 觉得《Brave New Words》仍相关：AI 会拓宽评估方式（不只家教，还有面试、口试）。他刚和 Caltech 招生负责人聊过：申请者交研究论文，有的像本人做的、有的看不清；他们已用 AI 对学生做口试，检验是否真懂——这是顶尖大学招生，赌注很高。

Khanmigo 已进课堂：对不少学生有用，但 1.0 是等学生来问，很多学生不会或不想问。他们在做更主动的新版本：促动机、加练习、教师在环——他强调不是为 AI 而 AI。

《Job Shock》的来由他分开讲了几条，不要串成一条因果链：

- 大约三四个月前（或更早），大学同学、现在做 VC 的朋友约他谈再培训。开车路上看到 Waymo，他觉得像活在未来；到办公室后，朋友说组合里一家公司用生成式 AI 把菲律宾某呼叫中心约 **80%** 人力自动化了，听起来是数百到数千人。朋友在考虑把公司利润约 **1%** 拿去再培训。菲律宾 BPO/呼叫中心按他的口径约占 GDP **5%、6% 或 7%**；若三到五年内成趋势，那些人做什么。
- 他是 Waymo 粉丝（TED 上采访过联合 CEO Tekedra Mawakana），觉得能救命、方便；但新奥尔良开 Uber 的叔叔怎么办。网约车往往不是第一选择工作。
- 硅谷同时在吵软工、产品、设计是合并还是少招。
- 书的缘起之一是他 12 月一篇《纽约时报》评论：不能只说工业革命最后工作变多了；工业革命也伴随战争、二十世纪很血腥、还有共产主义等实验。要有计划：工作可能怎样变、人该学什么、社会怎样适应。他大儿子高二，四五年后怎样还相关。

他明确不喜欢 UBI，材料里的替代说法是 **universal basic work**：人需要贡献感。没有展开成政策方案。

## 哪些工作会被动，哪些他觉得更倚赖人

Marina 问 Uber 司机还有多少时间：Waymo 花了约十年，而且现在主要还在旧金山。Sal：驾乘类大约 **五到十年** 才会真正咬到——比不少 AI 乐观派说的慢，但按一辈子仍快，会赶在孩子们上高中/大学前后。开车是全球男性最大就业之一（他也说刚坐的 Uber 司机是女性）。大量找不到工作、愤怒的人会进政治、走向极端。他怀疑 **今后四五年** 错位会开始真正出现，社会会卡在如何再培训。

其他：呼叫中心之外，他认为软工、设计、产品这些科技岗位（含 Khan Academy）正在根本改写。Marina 问这些人会不会流落街头——Sal **公开说不确定**。

相对更「安全」的，他点的是真正做人际的一侧：教师（他列过最安全之一，但角色要离开讲台上的 sage，变成规划、教练、对视、动机、苏格拉底式对话；他记得的好老师多半不是表演讲课）；护理、酒店、销售。销售他立刻收窄：电话销售、低成本销售 agent 会越来越强，部署成本极低，可能互相把收件箱炸到效力对冲；真正难替的是能建立关系、敢说「我们的产品不适合你」从而被信任的顾问。纯在电脑上完成、不必沟通/说服/倾听/协作的工作，他觉得会变或受威胁。

## Khan Academy 内部：多用 AI，但不因此裁员

约 **350** 人，约三分之二是产品侧。员工担心「三倍效率就裁掉三分之二」。Sal 对团队说的是：Khan Academy 预算大约一所大型高中，事情做不完；能用同样资源做三倍就做三倍，**不会以 AI 提效为裁员催化剂**。真会逼裁员的是筹款和自营收入不够。Anthropic 给他们的报告称，他们在「深入用这些工具」的组织里靠前。适应新工具已写入职业 rubric；他觉得多数人愿意跟上，卡住的是不想变的人。不适应的人，他认为 **五年内部分会有风险**。

角色在融合：上世纪 90 年代末到 2000 年代初那套「网页应用分工」在松。去年他听过有产品负责人强制 PM 做原型，当时觉得很大胆；现在 Khan Academy 给设计师和 PM 完整开发环境，可以 pull request、部署——仍偏原型/概念验证。工程师会更深、也更产能，也会出现更面向客户的一类。开发周期在加快。

两年内看起来不可思议、现在已进流程的：工程最明显。有人同时跑五到十个 agent 写代码、审代码；Anthropic 说他们是用 agent 做代码审查的最大用户之一。Anthropic 账单年化约 **120 万美元**且在涨，主要是大约 **200** 名工程师。有工程师单日算力他记得约 **3000 美元**，几小时做完原先约三到四个月的事——他觉得这钱该花。公司会上他又说：别拿 Opus 查附近餐厅，那种事用 Gemini / ChatGPT。逻辑是：一年用 100–300 万美元 token，若产出过去要 2000–3000 万美元，就该继续。黑客松里有工程师一天 vibe code 出功能，约一个月上线（旧世界可能要等下一学年）；组织体感相对两三年前至少快 **50%**、也许快 **100%**——他标明这是感觉，还没钉死。他们刚批准各 AI 接 Slack、Gmail、Docs；原则是人在环：别让它直接发社交、发邮件，可以起草。Sal 自己当参谋用：问「什么漏了」，过去约 **20–30%** 的请托会漏掉。提案：会后约 **10 分钟**有初稿（以前一两周），仍要人改。做理财视频时用 AI 查边界情况，但要看到 IRS.gov 一类来源才拍。

Marina 问会不会三年内 AI 自己再做一个 Khan Academy。Sal 给两套答案：情绪上会担心，三到五年 vibe code 出「看起来像」的东西他觉得有可能，但效力数据、学区隐私合规、和学校系统合作仍是摩擦，已有数百万用户和真实数据仍是优势。对团队的「正确」说法：作为非营利，若别人做出一样好或更好并证明确实有效，应该高兴，去解教育里别的题。他举标准化评估（不只选择题、要心理测量、叙事反馈）和文凭/学分补修/学位/就业路径——这些很难在车库 vibe code，市场也不太会自己来做新的标准化考试。

## Constellation Institute：补的是技能信号，不是再开一所藤校

与即将卸任的 TED steward Chris Anderson 的对话之后，Sal 接了 TED 的 vision steward。对方的逻辑：未来关乎目的、意义、连接，但没工作、没饭桌，很难谈意义。他们在 TED 宣布 **Constellation Institute**（后文字幕写成 Content Institute，指同一项目）：意图做成获认证项目，正在 pursuing accreditation；可能同时做四年制学士和硕士。学术块仍在（历史、civics、会计、统计，尤其学士）；差异化是全年龄学生进小组模拟：可能用 Schoolhouse 或类似，视频会议，限时约四小时做原型、广告、商业计划、调研等，然后互评沟通、协作、创造力。宣布后两三周约 **3000** 人想入学，多数已有学士、不少已有硕士，他读成「害怕、要重新证明自己还相关」。

Durable skills 他按 ETS 框架说大约五项：沟通、协作、创造力、批判性思维；领导力等在子框架（会上是否征求意见、沟通是否接住别人的话而不是各说各的）。启动时六家企业共创「你们明年希望人会做什么」：McKinsey、Bain、Google、Microsoft、Replit、Accenture。没人承诺「两年后第一届毕业就雇 20 人」；他们在重做岗位和面试。Sal 举例：家里有人在硅谷创业公司第三轮，要给医院 vibe code 一个方案再面对板——做完若没拿到 offer，作品就没了。他们想让学生做几十个更严的项目、作品集被评分、几十上百人反馈，简历长得不一样。对雇主的推销：名校 3.9 GPA 只能猜聪明和一点社团领导；他们希望沟通/协作/批判性思维前 10% 加视频证据，能与名校前 10% **至少同等优先**。

Marina 问会不会只打精英。Sal：高教很两极——哈佛一类申请七到八万、他认为五万人能读下来、只收约两千，其余进不了 Google/Bain 招人的池子；另一极是在线项目，好的如 Western Governors、Southern New Hampshire，对非传统路径有用，但很少拿到和四年名校同等信号。Constellation 想去掉「在线=低信号」的污名，也可服务不去精英、但要给区域雇主看信号的人。学费：整学位最多 **1 万美元**（本意更低）；能力本位不一定四年，可能两年。Marina 拿「四年四万 vs 传统四十万」问十年后还要不要存大学钱——Sal 纠正的是上限一万，不是沿用四万。

他自己儿子高二要申请大学：他在 MIT 遇妻，仍觉得寄宿名校是奢侈体验，希望孩子能去、也愿意为此花大约五十万美元。同时能想象孩子在名校之外再叠加 Constellation，因为工具迭代更快、和就业技能更直接。也有顶尖大学学生因创业窗口退学。多数学生其实是通勤、社区大学、为了找工作；他设想 Constellation 叠在社区大学或 Cal State 上：圣何塞州立全奖 + 大约五千美元的 Constellation，对比五十万美元去斯坦福只为了 McKinsey 来招。有条件给孩子名校体验他仍觉得是礼物，但也说半百万可以拿去旅行读书、创业、买 token、付首付。硅谷泡泡里有朋友说花二三十万美元买未自动化的夫妻店、让孩子去做周转——他当作另一种花钱方式，不是政策建议。

## 今后几年，以及个人层面他真正说了什么

Marina 认为不会出现「90% 人都没了」那种大裁员。Sal：希望她是对的，变化通常没那么快，但这次技术不一样。软工这两三年从「帮 20–30%」到转录里说的「Claude Code 时刻大约四五年前」之后变成「现在就这样写代码」（口述时间口径保留，不要改成外界日历）。知识工作也在进来。他的判断：**三四年内不会大规模失业**，但某些行业若出现 **4–5%** 失业也会很痛、会进政治；AI 还在加速，产业、政府、非营利若到那时还没有能规模化的方案，会有麻烦。

个人：最重要的是愿意试（创业/内部创业心态），跨过启动能，把生活和工作流一点点接到工具上，必要时沙箱、人在环——不是火箭科学。Durable skills、找反馈和导师、建人际。他让模型狠批自己，因为默认夸「Sal 你真有洞察」很诱人。若现在 22 岁、MIT 刚毕业：仍会去创业，**别往人挤的地方跑，去最空、最无聊、最适合套这些技术的行业**；并投资沟通协作。孩子若说找不到工作：他承认没有精确答案，家里也有年长者正在找工作困难；但此刻仍相对容易靠「带着 100 个 agent / 作品集 / 自动化的一天 Loom」制造区分度——类比 1996 年「我会做网页」。这种人他说明天就想招进 Khan Academy。儿子可能读计算机：五年前觉得很好，现在不确定，但仍值得读，因为它难、是信号，同时要做上面那些别的事。结尾 Marina 说「Google 75% 的代码已是 AI」——那是主持人的话，不是 Sal 的数据。
