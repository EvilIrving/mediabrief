What stays on your Mac

留在这台 Mac 上的内容

この Mac に残るもの

이 Mac에 남는 것

Video and audio files, Whisper models, FFmpeg work files, the history database, logs, and any browser cookies used for a site stay under ~/Library/Application Support/ai-transcriber/. MediaBrief does not operate a MediaBrief account or a MediaBrief cloud store for your files.

视频和音频文件、Whisper 模型、FFmpeg 中间文件、历史数据库、日志，以及用于某个站点的浏览器 Cookie，都放在 ~/Library/Application Support/ai-transcriber/。MediaBrief 不为你的文件提供账号，也不提供云端存储。

動画・音声、Whisper モデル、FFmpeg の作業ファイル、履歴データベース、ログ、サイト用のブラウザ Cookie は ~/Library/Application Support/ai-transcriber/ に残ります。MediaBrief はあなたのファイル用のアカウントやクラウド保存先を持ちません。

영상·오디오, Whisper 모델, FFmpeg 작업 파일, 기록 데이터베이스, 로그, 사이트용 브라우저 Cookie는 ~/Library/Application Support/ai-transcriber/에 남습니다. MediaBrief는 파일용 계정이나 클라우드 저장소를 두지 않습니다.

What is sent to an AI API

会发给 AI 接口的内容

AI API に送るもの

AI API로 보내는 것

Transcript text is sent to an upstream AI API for cleanup, summary, translation, and, when a download fails, recovery. The original video or audio file is not uploaded for those steps. What that API provider stores is governed by that provider, not by MediaBrief.

转录文本会发给上游 AI，用于整理、摘要、翻译，以及下载失败时的恢复。这些步骤不会上传原始视频或音频。上游会保存什么，由该服务商自己的条款决定，不是 MediaBrief 的服务器。

文字起こし本文は、整形、要約、翻訳、および取得失敗時の復旧のために上流の AI API へ送られます。その工程で元の動画や音声はアップロードしません。その事業者が何を保存するかは、その事業者の条件によります。

전사 텍스트는 정리, 요약, 번역, 그리고 받기에 실패했을 때의 복구를 위해 업스트림 AI API로 보내집니다. 그 단계에서는 원본 영상이나 오디오를 올리지 않습니다. 그 제공자가 무엇을 저장하는지는 해당 제공자의 조건입니다.

Cookies and login

Cookie 和登录

Cookie とログイン

Cookie와 로그인

If you allow a browser session for a site that needs it, MediaBrief reads cookies on this Mac only to fetch that media. Cookies, tokens, and login headers are not sent to the AI API and are not written into logs or diagnostics.

如果某个站点需要你允许使用浏览器会话，MediaBrief 只在这台 Mac 上读取 Cookie 来获取媒体。Cookie、令牌和登录头不会发给 AI 接口，也不会写进日志或诊断。

サイトが必要とする場合にブラウザセッションを許可すると、MediaBrief はそのメディア取得のためにこの Mac 上の Cookie だけを読みます。Cookie、トークン、ログイン用ヘッダは AI API に送らず、ログや診断にも書きません。

사이트가 필요할 때 브라우저 세션을 허용하면, MediaBrief는 그 미디어를 받기 위해 이 Mac의 Cookie만 읽습니다. Cookie, 토큰, 로그인 헤더는 AI API로 보내지 않으며, 로그나 진단에도 쓰지 않습니다.

Diagnostics

诊断

診断

진단

The app does not upload diagnostics automatically. You can copy a sanitized diagnostic or open the local log folder yourself. Check for Updates only opens the public download page.

应用不会自动上传诊断。你可以自己复制一份脱敏诊断，或打开本地日志目录。「检查更新」只会打开公开下载页。

診断の自動アップロードはありません。匿名化した診断を自分でコピーするか、ローカルのログフォルダを開けます。「更新を確認」は公開ダウンロードページを開くだけです。

진단은 자동으로 올리지 않습니다. 직접 익명화된 진단을 복사하거나 로컬 로그 폴더를 열 수 있습니다. "업데이트 확인"은 공개 다운로드 페이지만 엽니다.

How to delete local data

怎么删除本地数据

ローカルデータの消し方

로컬 데이터 삭제

Delete items in History, or quit MediaBrief and remove ~/Library/Application Support/ai-transcriber/. That folder also holds downloaded models and logs.

在历史里删除条目，或退出 MediaBrief 后删掉 ~/Library/Application Support/ai-transcriber/。这个文件夹里还有下载的模型和日志。

履歴から項目を削除するか、MediaBrief を終了して ~/Library/Application Support/ai-transcriber/ を削除します。このフォルダにはダウンロード済みモデルとログも含まれます。

기록에서 항목을 지우거나, MediaBrief를 종료한 뒤 ~/Library/Application Support/ai-transcriber/를 삭제하세요. 이 폴더에는 받은 모델과 로그도 있습니다.
